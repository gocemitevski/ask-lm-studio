LM Studio connection

Use inside Firefox's built-in AI chatbot?

Firefox does not allow extensions to add themselves to the built-in Gemini / ChatGPT provider list via WebExtensions API. Use Enterprise Policy (see policies/lm-studio.json) or manual about:config below. The native chatbot just iframes a web-chat URL, so point it at a web UI fronting LM Studio (e.g. Open WebUI → LM Studio).

Manual test: set browser.ml.chat.provider to http://localhost:3000/?temporary-chat=true and browser.ml.chat.hideLocalhost=false. Pasting this extension's own URL (Copy URL) is experimental — Firefox may refuse to iframe moz-extension:// pages from the chatbot, so verify it actually loads in your version before relying on it. See README §4.
